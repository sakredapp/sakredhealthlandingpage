# Image prompts — batch 2, the remaining 29 posts

## How to use this

Paste **one numbered prompt at a time**. Each is self-contained — do not paste the
whole file at once, and do not paste the headers or this section.

**Dimensions.** Do not ask for "1200x630" — image models handle that badly. Ask for
**wide landscape**, generate at **1536 × 1024**, then centre-crop to 1200 × 630. Every
prompt below already says this and leaves headroom at the top and bottom of the frame
so the crop never cuts the subject.

**Format.** Save as **JPEG**, quality ~85. Name the file exactly
`<post-slug>.jpeg` — the slug is printed above each prompt. Upload to the
`blogimages` bucket. No further wiring needed; it will attach automatically.

**Why these look different from each other.** The last batch drifted into one look —
warm light, wooden board, shallow focus, every time. Each prompt below locks a
*specific* camera angle, light source, colour palette and surface, and they are
deliberately rotated. If two images come back looking like siblings, the palette or
lighting line got dropped — put it back and regenerate.

**Applies to all 29:** photographic, not illustration or 3D render. No text, no
lettering, no numbers, no logos, no brand marks, no packaging labels, no watermarks.
No people's faces unless the prompt explicitly asks. No AI-glossy plastic sheen.
