# Image prompts — 20 images, plus 3 optional extras

**These are 23 separate images, not one.** Each block below is a complete,
self-contained prompt. Paste **one block at a time** into ChatGPT and generate
that image, then move to the next. Nothing needs to be combined or prepended —
the style and the rules are already inside every prompt.

Images 1–20 are the set. Extras A–C at the bottom are optional.

After each image: save it as the filename listed under the prompt, and drop the
file into `client/public/images/blog/`. Send them to me and I'll wire the
frontmatter in.

**Order doesn't matter, but 1–8 are the ones worth doing first** — those posts
are current, getting traffic, and are the ones with no artwork at all.

# Notes

**Why every prompt bans text and logos.** Generated lettering is almost always
subtly malformed and is the clearest visual tell that an image was
machine-made. And several of these posts name Starbucks, Dunkin', Cinnabon and
Swiss Miss while carrying a non-affiliation disclaimer — depicting their
branding would contradict it.

**Two prompts have hard content constraints** that exist because the image would
otherwise contradict the article it sits on. Image 11 must contain no
marshmallows, because that post argues against the marshmallow version. Image 9
needs Ceylon bark to look different from cassia, because the difference between
them is the point of the article. If a generated image gets those wrong,
regenerate rather than accepting it.

**Sizing.** 1200x630 landscape, saved as JPG, ideally under about 200 KB each.
