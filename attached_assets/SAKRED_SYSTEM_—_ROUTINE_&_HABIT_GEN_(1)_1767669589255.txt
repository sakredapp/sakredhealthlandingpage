SAKRED SYSTEM — ROUTINE & HABIT GENERATION RULES (v1)

This document defines how the system generates and structures routines and habits.  
It must stay aligned with:

- Premium_Routine_and_Habit_Modules_Clean.txt  
- routine split primer.txt  
- Sakred App Free_ Product Copy.txt  
- premium_habits_database.txt  

This is backend logic. Do not include tone, empathy, or coach-style wording.

------------------------------------------------------

1. CORE PURPOSE

The system must:
- Construct routines using only predefined habits.
- Select habits safely and intelligently.
- Respect free vs premium rules.
- Honor lite / standard / intense lanes.
- Maintain Sakred’s terrain-first sequencing: hydration → minerals → digestion → nervous system → detox → rebuild.

------------------------------------------------------

2. DEFINED ENTITIES

Habit = a single structured action.  
Routine = an ordered set of habits supporting a specific goal.  
Lane = intensity tier (lite / standard / intense).  
Tier = free or premium.  
Goal = user-selected outcome category.

------------------------------------------------------

3. HABIT DATA REQUIREMENTS

Every habit must include:

- habit_id  
- name  
- category (hydration, digestion, sleep, movement, breathwork, supplement, detox, reflection)  
- terrain_tags (hydration, digestion, drainage, detox, nervous-system, metabolic, skin, cycle)  
- intensity_level (lite / standard / intense)  
- recommended_time (morning, pre-meal, post-meal, evening, anytime)  
- frequency_default  
- max_frequency (if relevant)  
- prerequisites (hydration, minerals, digestion, etc.)  
- pairing_conflicts (list of habit_ids or terrain tags)  
- copy_block_id (for Coach explanations)  
- is_free (boolean)  
- requires_products (boolean)  
- products_needed (list)

Rules:
- No habit may be generated dynamically. Only select from the database.
- No habit may be included without `copy_block_id`.

------------------------------------------------------

4. ROUTINE DATA REQUIREMENTS

Each routine must include:

- routine_id  
- name  
- lane (lite / standard / intense)  
- tier (free / premium)  
- goal_tags  
- duration_default  
- habit_ids (ordered list)  
- max_daily_habits  
- terrain_distribution summary  
- warnings (optional)

------------------------------------------------------

5. ROUTINE GENERATION SEQUENCE (HARD RULES)

When constructing a routine:

STEP 1 – Identify candidate routine templates  
- Match routines whose goal_tags relate to the user’s selected goal.  
- Filter by tier (free or premium).  
- Default lane = lite unless user chooses otherwise.

STEP 2 – Habits selection  
For each chosen routine template:
- Pull associated habits.
- Validate: habit exists, intensity fits lane, `copy_block_id` is valid.

STEP 3 – Apply habit count rules  
- Lite: 3–6 habits  
- Standard: 5–9 habits  
- Intense: 7–12 habits  
(Soft bounds that can be overridden by human admins.)

STEP 4 – Apply terrain balancing  
Every routine must include:  
- ≥1 hydration/mineral habit  
- ≥1 nervous-system/recovery habit  
- Maximum 2–3 detox-heavy habits in any lane  
- Ensure digestion support exists if detox habits exist.

STEP 5 – Apply conflicts  
For all selected habits:  
- Remove habits that conflict with any other habit’s `pairing_conflicts`.  
- If multiple detox or high-output habits conflict, keep the simpler one.

STEP 6 – Check prerequisites  
- Ensure foundational habits (hydration, minerals, digestion) precede detox or output habits.  
- Add missing prerequisites automatically if tier + lane allows.

STEP 7 – Order habits  
Required order inside a routine:  
1. Hydration + minerals  
2. Digestion support  
3. Nervous-system support  
4. Movement / metabolic support  
5. Detox habits (only if prerequisites satisfied)  
6. Regeneration / sleep habits

STEP 8 – Validate final routine  
- Ensure no missing copy blocks.  
- Ensure no unbalanced terrain category overloads.  
- Ensure lane-based intensity requirements align.

------------------------------------------------------

6. LANES (LITE / STANDARD / INTENSE)

LITE:
- Only foundational habits.
- No advanced detox.
- No high-output stressors.
- Lowest frequency.

STANDARD:
- Adds 1–3 upgrade habits.
- Allows mild detox.
- Includes moderate movement habits.

INTENSE:
- For consistent users only.
- Allows advanced detox and higher-frequency movement.
- Must always include hydration + minerals + nervous-system anchors.
- Reduce or remove if user reports low recovery.

------------------------------------------------------

7. FREE VS PREMIUM RULES

FREE ROUTINES:
- Only include habits where `is_free = true`.
- Must use routines defined in Sakred App Free_ Product Copy.txt.
- No advanced detox or complex supplement stacks.
- Habit count should be lower.

PREMIUM ROUTINES:
- Can access the full habit database.
- Can include detox, advanced tools, and supplement-based habits.
- Terrain balancing still required.

------------------------------------------------------

8. SAFETY & TERRAIN-SEQUENCING RULES

- Never include detox without hydration + minerals.  
- Never include high-output + detox on the same day without nervous-system support.  
- Never include more than one new stressor habit at a time in lite.  
- Never include a product-required habit if user lacks access.  
- Avoid fasting + advanced detox + heavy training combinations by default.

------------------------------------------------------

9. UPDATE BEHAVIOR

When updating or versioning routines:
- Keep routine_ids constant unless the structure changes substantially.
- Increment version numbers for global changes.
- Maintain integrity with Premium_Routine_and_Habit_Modules_Clean.txt.
